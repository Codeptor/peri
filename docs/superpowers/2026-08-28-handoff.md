## Current configured trading policy

From `config.toml`:

```toml
[analyst]
cycle_secs = 900
conviction_min = 0.75

[risk]
risk_pct = 1.5
max_leverage = 20.0
max_concurrent = 3
daily_entry_cap = 6
kill_switch_pct = 15.0
min_rr = 2.0
min_notional = 10.0
```

The frozen open gate in `src/peri/risk.py` sizes by stop distance:

```text
risk_usd = equity * risk_pct / 100
notional = risk_usd / stop_distance_fraction
margin = notional / leverage
```

Leverage changes required margin for a given notional; it does not itself make
the same notional earn more dollars. Perp PnL is driven by position size and the
entry-to-exit price move. See Hyperliquid's official
[entry/PnL](https://hyperliquid.gitbook.io/hyperliquid-docs/trading/entry-price-and-pnl)
and [margining](https://hyperliquid.gitbook.io/hyperliquid-docs/trading/margining)
documentation.

   3R-4R at this equity after fees. Do not fake the target with a tighter noise

## What is already shipped

### peri backend

- Live mainnet Hyperliquid execution with Trench builder routing and SL+TP
  brackets on opens.
- Venue reconciliation is the source of truth for positions, orders, closes,
  realized PnL, and adoption of unknown external positions.
- Qwen receives current account/position/order context, market features,
  Telegram messages, RSS/TG news, recent closes, and search tools.
- One immediate manual wake endpoint plus caller-message wake; scheduled cycles
  use fixed cadence.
- Telegram `NewMessage` **and `MessageEdited`** events are ingested and tested.
- Analyst chat streams via SSE, uses fresh upstream context, persists history,
  emits immutable 120-second trade proposals, revalidates against fresh state,
  and only executes after explicit confirmation.
- Dashboard live snapshots are coalesced, preserve a stale last-good snapshot,
  and stream through a shared WebSocket.
- Live order provenance includes placement role, position source, decision ID,
  route, and attribution quality.

### periboard

- Overview includes live positions followed by the live order/provenance table.
- Shared WebSocket updates account, positions, orders, closes, realized PnL,
  and runtime status.
- `/analyst` provides streamed Qwen chat, real context, confirmation cards, and
  position-management requests.
- Header has the manual `Wake Qwen` control.
- Decision feed/detail and every consumer of `stamp()` now render exact
  `Asia/Kolkata` timestamps; the shared header has a live one-second IST clock.
- Stale upstream data is visibly surfaced instead of silently freezing.

### Telegram limitation

Edited text messages are wired. Images are **not** automatically included in
the live analyst context. `scan_media.py` can download sampled media manually,
but `src/peri/feed.py` currently ingests text only. Do not claim Qwen sees image
content until a real media/OCR or multimodal ingestion path is implemented and
tested.
